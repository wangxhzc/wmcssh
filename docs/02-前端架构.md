# 前端架构

## 1. 目录分层

```text
src/
  app/                    应用入口
  features/
    hosts/                主机列表与主机表单
    terminal/             终端标签、xterm 视图、连接动作
    file-transfer/        文件传输标签页
    layout/               整体壳布局
  services/
    tauri/                invoke / event 封装
    terminal/             base64、输入输出编解码
  stores/                 Zustand 状态
  types/                  前后端 DTO 类型
```

## 2. 状态划分

### 2.1 Zustand

- `hostStore`
  - 主机列表
  - 加载状态
  - 搜索关键字
- `terminalStore`
  - 工作区标签列表
  - 活动标签
  - 终端标签状态
  - 终端标签与文件传输标签的混合管理
- `settingsStore`
  - 终端设置

### 2.2 运行时对象

- `terminalRegistry`
  - 保存 xterm 实例、FitAddon、disposables
- `sessionTabIndex`
  - `sessionId -> tabId` 映射

## 3. 标签模型

当前工作区标签分成两类：

```ts
type WorkspaceTabKind = "terminal" | "file-transfer";
```

- `terminal`
  - 有 `sessionId`
  - 有连接状态
  - 由 SSH 事件驱动
- `file-transfer`
  - 无 `sessionId`
  - 用于远程目录浏览与传输

## 4. 终端数据流

```text
HostSidebar click
  -> connectHost()
  -> createTerminalTab()
  -> ssh_connect()
  -> bind sessionId
  -> ssh:status / ssh:error / ssh:closed
  -> sessionId 映射 tabId
  -> terminalRegistry.write()
```

终端输出不会进入 React 组件状态，避免大流量渲染抖动。

## 5. 文件传输页数据流

```text
HostSidebar 右键 -> 文件传输
  -> createFileTransferTab()
  -> FileTransferView mount
  -> ssh_list_remote_directory()
  -> 渲染远程目录
```

上传：

```text
原生文件选择器
  -> readFile()
  -> ssh_upload_remote_file()
  -> 刷新当前目录
```

下载：

```text
文件右键 -> 下载
  -> ssh_download_remote_file()
  -> 原生保存对话框
  -> writeFile()
```

## 6. 当前关键组件

- `HostSidebar`
  - 主机列表
  - 主机右键菜单
  - 新建 / 编辑主机弹窗
- `TerminalWorkspace`
  - 顶部标签栏
  - 中部内容区
  - 底部状态栏
- `TerminalView`
  - xterm 实例挂载
  - 终端上下文菜单
- `FileTransferView`
  - 远程目录浏览
  - 上传 / 下载

## 7. 当前前端限制

- 文件传输没有本地目录树
- 没有传输进度条
- 没有最近连接 UI
- 没有设置页 UI
- 主机分组和标签仅在数据模型 / 数据库层预留
