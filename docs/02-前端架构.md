# 前端架构

## 目录分层

| 目录 | 职责 |
| --- | --- |
| `src/app/` | 应用装配 |
| `src/features/layout/` | 壳布局与自定义标题栏 |
| `src/features/hosts/` | 主机管理、快速连接、认证与指纹确认 |
| `src/features/terminal/` | 标签、xterm、输入输出与 OSC 集成 |
| `src/features/file-transfer/` | 文件管理与传输队列 |
| `src/features/settings/` | 设置中心和草稿处理 |
| `src/features/vault/` | 凭据库初始化和解锁 |
| `src/services/tauri/` | 原生命令、事件和插件的类型化封装 |
| `src/services/terminal/` | 终端编解码 |
| `src/stores/` | Zustand 状态 |
| `src/types/` | DTO 和界面类型 |

## 状态与资源

`hostStore` 管理主机列表、搜索和加载状态；`terminalStore` 管理混合工作区标签、
活动标签和连接状态；`settingsStore` 管理终端设置；`transferQueueStore` 管理任务进度；
`terminalNoticeStore` 管理远端通知。

`terminalRegistry` 持有 xterm 实例、插件、数据通道及清理资源，
`sessionTabIndex` 维护 `sessionId → tabId` 索引。高频输出直接写入终端实例。
终端标签使用 `sessionId`，文件标签使用 `transferSessionId`，真实连接资源由 Rust 管理。

## 终端数据流

```text
主机连接 / 快速连接
  → 获取凭据并按用户选择保存
  → 创建标签与终端实例
  → 生成 sessionId，绑定标签、索引与注册表
  → ssh_connect(input, onData)
  ├─ Channel → Base64 解码 → terminalRegistry → xterm 解析 → ssh_ack_output
  └─ ssh:status / ssh:error / ssh:closed → 标签状态
```

输入经短时合并和 Unicode 安全分块后调用 `ssh_write`，输入额度满时按顺序重试。
FitAddon 测量尺寸并同步后端。切换标签复用实例，关闭时释放资源，重连使用新会话 ID。

渲染优先采用 WebGL，失败或上下文丢失后回退 DOM。额外高亮按渲染状态启用，
详见 [终端输出高亮](08-终端输出高亮.md)。

## 文件传输数据流

```text
打开文件标签 → ssh_open_file_transfer_session → transferSessionId
  → ssh_list_remote_directory → 展示目录

原生选择器 / 拖放 → 本地路径与目录枚举
  → ssh_enqueue_upload_remote_file / ssh_enqueue_upload_remote_directory
  → 后端流式读取 → 进度 Channel / 任务查询 → 队列界面

下载所选项 → 原生保存或目录选择器 → 本地目标路径
  → ssh_enqueue_download_remote_path → 后端暂存并替换目标
  → 进度 Channel / 任务查询 → 队列界面
```

文件页提供路径导航、选择、重命名、确认删除及系统默认程序打开。
上传队列空闲后刷新目录，非活动页在切回后刷新。关闭页面时释放页面持有的会话引用，
已提交任务继续使用后端资源；连接完成前关闭页面时清理迟到的会话。

## 设置与交互

组件通过 `src/services/tauri/` 调用原生命令和插件。设置中心维护可跨分类保留的草稿，
保存后应用于当前和后续终端。弹窗共用焦点约束，异步剪贴板操作校验焦点和当前会话。

能力与限制见 [项目现状](07-项目现状.md)，桌面验证见 [开发说明](06-开发路线图.md)。
