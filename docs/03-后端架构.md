# Rust 后端架构

## 模块职责

| 目录 | 职责 |
| --- | --- |
| `commands/` | Tauri 命令入口 |
| `contracts/` | 输入、输出、事件与错误 DTO |
| `db/` | SQLite 初始化与迁移 |
| `repositories/` | 主机、分组、标签、近期会话和设置访问 |
| `services/` | 主机业务、设置、文件操作与传输调度 |
| `secrets/` | 加密凭据库与旧版迁移 |
| `ssh/` | SSH worker、连接基础、主机密钥与 shell 集成 |
| `utils/` | 编解码、时间和标识工具 |

`lib.rs` 初始化数据库、凭据库和服务，装配 `AppState` 并注册命令。
命令索引见 [API 契约](04-API契约.md)。

## SSH 生命周期

`SessionManager` 接收或生成会话 ID，校验唯一性，注册句柄并启动阻塞 worker。
前端预先传入 ID，使早于命令返回的事件也能定位标签。

`SessionWorker` 执行 TCP 连接、握手、主机密钥校验、认证、PTY 请求和 shell 启动，
随后循环处理输出、输入、尺寸变化、保活和断开。连接使用
`ssh2 → libssh2 → OpenSSL`，Linux 与 Windows 均构建静态 OpenSSL。

输出通过 `Channel<SshDataEvent>` 发送，前端解析确认后释放额度，达到上限时暂停读取。
输入队列和待发送字节分别有容量限制，主动断开独立处理。
worker 正常退出、失败或 panic 后，管理器清理句柄。

## SFTP 会话与调度

`FileTransferService` 为每个文件页建立独立 SSH/SFTP 会话，在文件操作之间复用。
同一会话串行访问，不同会话使用独立锁；阻塞操作交给后台阻塞线程。
页面关闭后，已提交任务继续持有传输所需资源。

调度器使用固定 4 个 worker，同一会话按提交顺序执行，跨会话可并行。
任务状态为排队、运行、完成、失败和取消，支持进度 Channel、查询、取消和删除结束记录。
队列保存在进程内存中，退出后任务不恢复。

上传和下载先写暂存路径，成功后替换目标，失败或取消时清理暂存内容。
递归上传遇到已有同名目录时失败。扫描、删除和任务数量使用传输配置限制。

重命名在原父目录内执行并检查冲突。递归删除先预检目录树，符号链接按链接处理；
执行中失败可能留下部分删除结果。打开远端文件时检查类型和 10 MiB 上限，
下载至应用缓存后交给系统默认程序，后续打开操作清理超过 7 天的副本。

## 凭据与信任

`HostService` 校验配置并从 `SecretStore` 读取认证凭据，临时凭据覆盖本次连接参数。
更新凭据先写新引用，主机配置提交成功后清理旧引用，失败时清理新引用并保留原凭据。

`EncryptedSecretStore` 使用 Argon2id 和 XChaCha20-Poly1305，将密文保存至 SQLite。
`HostKeyStore` 管理 `known_hosts`，在 SSH/SFTP 认证前校验指纹。
数据库与迁移机制见 [数据库设计](05-数据库设计.md)。
