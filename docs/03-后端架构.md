# Rust 后端架构

## 1. 模块结构

```text
src-tauri/src/
  commands/        Tauri command 入口
  contracts/       前后端 DTO 契约
  db/              SQLite 初始化与 migration
  repositories/    数据访问
  services/        业务服务
  secrets/         敏感信息存储
  ssh/             SSH / SFTP 连接逻辑
  utils/           base64、时间、id 等工具
```

## 2. 当前服务层

- `HostService`
  - 主机校验
  - 构造 SSH 连接配置
  - 读取密码 / 私钥口令
- `FileTransferService`
  - 列目录
  - 上传文件
  - 下载文件
- `SettingsService`
  - 终端设置读写
- `RecentSessionRepository`
  - 最近连接查询

## 3. SSH 终端连接模型

`ssh_connect` 不直接在 async 任务里做长连接读写，而是：

```text
SessionManager
  -> 生成 sessionId
  -> 建立 command channel
  -> spawn_blocking(SessionWorker)
```

`SessionWorker` 负责：

- TCP 连接
- SSH handshake
- password / private key 认证
- PTY 请求
- shell 启动
- 循环读输出
- 处理 `Write / Resize / Disconnect`

## 4. 文件传输模型

文件传输不复用 `SessionWorker`，由 `FileTransferService` 直接按主机配置建立短生命周期的 SFTP 连接。

这样做的结果是：

- 终端和文件传输相互隔离
- 实现简单
- 便于独立失败和重试
- 代价是每次目录操作 / 上传 / 下载都需要单独握手

## 5. 命令边界

### Host Commands

- `create_host`
- `update_host`
- `delete_host`
- `get_host`
- `list_hosts`

### SSH Commands

- `ssh_connect`
- `ssh_write`
- `ssh_resize`
- `ssh_disconnect`

### File Transfer Commands

- `ssh_list_remote_directory`
- `ssh_upload_remote_file`
- `ssh_download_remote_file`

### Settings / Recent

- `get_terminal_settings`
- `update_terminal_settings`
- `reset_terminal_settings`
- `list_recent_sessions`
- `get_app_info`

## 6. 敏感信息策略

- SQLite 只保存 `password_ref` / `passphrase_ref`
- 实际密码和私钥口令保存在应用数据目录下的 `wmcssh.json`
- `HostDto` 不回传明文密码

## 7. 当前已知限制

- SFTP 目前只支持列目录、上传、下载
- 目录操作没有进度通知
- 文件传输没有后台队列
- 没有 SSH 连接池或 SFTP 连接复用
