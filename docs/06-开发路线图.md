# 开发说明

这份文档不再记录早期 MVP 路线图，改为记录当前项目状态、开发命令和推荐后续工作。

## 1. 当前实现状态

已完成：

- Tauri 2 + React 基础壳
- SQLite 初始化与 migration
- 主机增删改查
- 密码 / 私钥 SSH
- xterm 终端渲染
- 连接状态事件
- 终端重连
- 最近连接记录入库
- 文件传输目录浏览
- 文件上传 / 下载
- 原生文件选择 / 保存对话框接入

未完成：

- 最近连接页面
- 设置页面
- 文件传输进度和批量队列
- 文件删除 / 重命名
- 分组 / 标签 UI

## 2. 常用命令

安装依赖：

```bash
npm install
```

前端开发：

```bash
npm run dev
```

桌面开发：

```bash
npm run tauri dev
```

前端构建：

```bash
npm run build
```

Rust 检查：

```bash
cd src-tauri && cargo check
```

Linux 打包：

```bash
npm run build:linux:amd64
```

Windows 打包：

```bash
npm run build:windows:amd64
```

## 3. 调试建议

- 文件传输失败同时看通知和终端控制台日志
- SSH 连接问题优先看 `ssh:error` 事件信息
- 如修改了 `src-tauri/capabilities/default.json`，需要重启应用让权限生效

## 4. 推荐后续开发顺序

1. 文件传输补删除、重命名、覆盖确认
2. 做最近连接 UI
3. 做设置页，接通已有 settings API
4. 做主机分组 / 标签管理 UI
5. 根据需要再考虑连接复用、跳板机、端口转发
