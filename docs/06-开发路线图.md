# 开发说明

本文说明开发与验证流程。能力和后续重点见 [项目现状](07-项目现状.md)，
平台依赖与打包要求见 [README](../README.md)。

## 常用命令

在仓库根目录执行：

| 命令 | 用途 |
| --- | --- |
| `npm install` | 安装依赖 |
| `npm run dev` | 启动 Vite |
| `npm run tauri dev` | 启动 Tauri 桌面开发环境 |
| `npm run dev:windows:amd64` | 在 Windows 使用 GNU 工具链启动桌面开发环境 |
| `npm test` | Node 逻辑测试 |
| `npm run build` | TypeScript 检查与 Vite 构建 |
| `cargo check --manifest-path src-tauri/Cargo.toml` | Rust 编译检查 |
| `cargo test --manifest-path src-tauri/Cargo.toml` | Rust 测试 |
| `cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check` | Rust 格式检查 |
| `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --all-features -- -D warnings` | Rust 静态检查 |
| `npm run build:linux:amd64` | Linux amd64 DEB |
| `npm run build:windows:amd64` | Windows GNU amd64 NSIS |

## 调试与验证

前端变更运行测试和构建；后端变更运行 Rust 格式、测试和 Clippy。
Node 测试覆盖可独立验证的 TypeScript 逻辑，原生命令和桌面交互在 Tauri 中验证。

桌面回归关注标题栏、窗口控制、快速连接、菜单焦点、终端 I/O 与尺寸变化、
凭据库、主机密钥及递归传输。界面变更记录截图，剪贴板、拖放和文件对话框在目标平台验证。

连接问题结合 `ssh:error`、界面反馈和应用日志定位，传输问题同时检查任务错误与
目录状态。日志和调试输出须保护密码、私钥口令与密钥。
修改 `src-tauri/capabilities/default.json` 后重启应用，使权限生效。

## 发布与维护

质量 CI 在 Linux 运行前端测试与构建，以及 Rust 格式、测试和 Clippy。
发布工作流由 `v*` 标签或手动触发，使用锁定 Rust 依赖生成 Linux DEB 和 Windows
NSIS 并发布至 GitHub Release。Windows 使用 GNU 工具链与 MSYS2 MINGW64。

数据库变更添加向前迁移；契约变更同步 Rust DTO、命令注册、TypeScript 类型和封装。
生成目录、安装包、数据库与日志保留在本机。产品行为、架构、安全或发布流程变化时
同步更新项目现状。
