# wmcssh 设计总览

## 1. 项目定位

`wmcssh` 是一个桌面 SSH 工作台，目标不是单一“命令行窗口”，而是把主机管理、终端会话和基础文件传输放到同一个桌面应用里。

当前版本的设计重点是：

- 本地优先
- 单机使用
- UI 简单直接
- 终端 IO 稳定
- 敏感信息不进 SQLite

## 2. 当前功能边界

已实现：

- 主机新增、编辑、删除、搜索
- 密码 / 私钥认证
- 多标签 SSH 终端
- 终端状态事件同步
- 标签关闭、断开、重连
- 远程目录浏览
- 远程文件上传 / 下载
- 最近连接记录入库
- 终端设置持久化

未实现或未暴露：

- 最近连接页面
- 分组树和标签管理页面
- 设置页面
- 跳板机、端口转发
- 文件删除、重命名、拖拽上传

## 3. 技术栈

```text
Tauri 2
React + TypeScript
Zustand
xterm.js
Rust
ssh2
SQLite
Tauri Dialog / FS / Opener
```

## 4. 总体架构

```text
React UI
  ├─ HostSidebar
  ├─ TerminalWorkspace
  │   ├─ Terminal tabs
  │   ├─ Terminal views
  │   └─ File transfer views
  └─ Zustand stores

Tauri Bridge
  ├─ commands
  ├─ events
  └─ Channel<SshDataEvent>

Rust Core
  ├─ HostService / SettingsService / FileTransferService
  ├─ SessionManager / SessionWorker
  ├─ SQLite repositories
  └─ SecretStore

Local Storage
  ├─ SQLite
  └─ wmcssh.json secret cache
```

## 5. 关键设计决策

- 终端输出不进 React state，直接写 xterm。
- SSH 会话由 Rust `SessionWorker` 独占。
- 一个终端标签对应一个 SSH 会话。
- 文件传输不复用终端 `sessionId`，单次操作按主机配置新建 SFTP 连接。
- 远程文件传输默认进入家目录，失败回退 `/`。
- SQLite 只存结构化配置，不存密码和私钥口令。

## 6. 当前 UI 结构

```text
AppShell
  ├─ HostSidebar
  │   ├─ 搜索框
  │   ├─ 新建主机
  │   ├─ 主机卡片
  │   └─ 主机右键菜单
  └─ TerminalWorkspace
      ├─ TerminalTabBar
      ├─ TerminalPane
      │   ├─ TerminalView
      │   └─ FileTransferView
      └─ TerminalStatusBar
```

## 7. 运行数据边界

- `Host`：主机配置
- `TerminalTab`：终端标签
- `FileTransferTab`：文件传输标签
- `SshSession`：Rust 侧真实终端连接
- `RecentSession`：历史连接记录
- `TerminalSettings`：终端渲染配置
