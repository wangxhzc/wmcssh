# wmcssh 设计总览

## 项目定位

wmcssh 是面向 Linux 和 Windows 的桌面 SSH 工作台，将主机管理、多标签终端、
快速连接和 SFTP 文件传输整合到同一应用。技术栈为 Tauri 2、React、TypeScript、
Zustand、xterm.js、Rust、ssh2 和 SQLite。

当前能力、限制和验证记录见 [项目现状](07-项目现状.md)。

## 组件关系

```text
React UI
  ├─ AppShell / AppTitleBar
  ├─ 主机管理 / 快速连接 / 设置中心 / 凭据库弹窗
  ├─ TerminalWorkspace
  │   ├─ TerminalView → terminalRegistry → xterm.js
  │   └─ FileTransferView → 传输队列
  └─ Zustand stores
           ↓ 类型化命令、事件与 Channel
Rust Core
  ├─ HostService / SettingsService
  ├─ SessionManager → SessionWorker
  ├─ FileTransferService → SFTP 会话 / 后台调度器
  ├─ SQLite repositories
  ├─ EncryptedSecretStore
  └─ HostKeyStore
```

## 会话与数据流

终端标签持有会话标识和展示状态。前端在连接前生成并绑定会话 ID，Rust worker
执行握手、主机密钥校验、认证、PTY 和 shell I/O。输出经 Tauri Channel 进入终端注册表，
xterm 完成解析后回传确认，后端据此控制输出额度。状态和错误通过事件更新界面。

每个文件标签建立独立的 SSH/SFTP 会话，在目录浏览和传输之间复用连接。前端提交
本地与远端路径，后端流式读写文件，并通过进度 Channel 和任务查询更新队列。
关闭文件页后，已提交任务继续运行。

## 本地存储

SQLite 保存业务配置、近期会话、设置和加密凭据。主机通过凭据引用关联密文，
主密码经 Argon2id 派生主密钥，秘密值使用 XChaCha20-Poly1305 加密。
解锁后的主密钥驻留进程内存，释放时清零。

应用数据目录还保存服务器密钥信任记录 `known_hosts`、传输限制
`transfer-config.json` 和窗口尺寸 `window-state.json`。
旧版 `wmcssh.json` 在凭据库初始化时迁移，完成后删除。

详细机制见 [前端架构](02-前端架构.md)、[后端架构](03-后端架构.md)
和 [数据库设计](05-数据库设计.md)。
