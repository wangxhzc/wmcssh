# 数据库设计

## 1. 原则

- SQLite 保存结构化业务数据
- 敏感信息不进 SQLite
- 密码 / 私钥口令只保存引用 key

## 2. Migration

当前数据库 migration 位于：

```text
src-tauri/migrations/0001_init.sql
```

启动时通过：

```rust
sqlx::migrate!("./migrations").run(pool).await?;
```

自动执行。

## 3. 当前核心表

- `host_groups`
- `hosts`
- `tags`
- `host_tags`
- `recent_sessions`
- `settings`

## 4. hosts 表

```sql
CREATE TABLE hosts (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  hostname TEXT NOT NULL,
  port INTEGER NOT NULL DEFAULT 22,
  username TEXT NOT NULL,
  auth_type TEXT NOT NULL,
  password_ref TEXT,
  private_key_path TEXT,
  private_key_ref TEXT,
  passphrase_ref TEXT,
  group_id TEXT,
  startup_command TEXT,
  terminal_theme TEXT,
  connect_timeout_ms INTEGER NOT NULL DEFAULT 10000,
  keepalive_interval_secs INTEGER NOT NULL DEFAULT 30,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
```

说明：

- `password_ref` / `passphrase_ref` 指向本地 secret store
- `private_key_ref` 目前保留，当前实现主要使用 `private_key_path`

## 5. recent_sessions 表

```sql
CREATE TABLE recent_sessions (
  id TEXT PRIMARY KEY,
  host_id TEXT NOT NULL,
  session_id TEXT,
  started_at INTEGER NOT NULL,
  ended_at INTEGER,
  status TEXT NOT NULL,
  error_code TEXT,
  error_message TEXT,
  duration_seconds INTEGER
);
```

用途：

- 记录终端 SSH 会话的最近连接历史
- 当前后端已写入与查询
- 当前前端还没有对应页面

## 6. settings 表

```sql
CREATE TABLE settings (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL,
  updated_at INTEGER NOT NULL
);
```

当前主要用于保存终端设置。

## 7. tags / groups

数据库已经预留：

- `host_groups`
- `tags`
- `host_tags`

但当前前端还没有完整的分组树和标签编辑界面，所以这些能力现在主要属于数据模型预留。

## 8. Secret 引用规则

当前约定：

```text
password_ref   = host:<host_id>:password
passphrase_ref = host:<host_id>:private_key_passphrase
```

真实内容保存到应用数据目录下的：

```text
wmcssh.json
```
