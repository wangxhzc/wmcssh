# 数据库设计

## 存储与迁移

应用使用 Tauri 应用数据目录下的 `wmcssh.sqlite`，启用外键、WAL 和 3000ms
忙等待。启动时通过 `sqlx::migrate!("./migrations")` 执行迁移。

| 迁移 | 内容 |
| --- | --- |
| `0001_init.sql` | 主机、分组、标签、近期会话、设置及索引 |
| `0002_credential_vault.sql` | 凭据库元数据和加密凭据 |

结构调整通过新增迁移完成，保留已发布迁移和用户数据。
完整 SQL 见 [迁移目录](../src-tauri/migrations/)。

## 业务表

| 表 | 用途与关系 |
| --- | --- |
| `hosts` | 连接配置、凭据引用、私钥路径、超时、保活、启动命令、主题、排序和时间 |
| `host_groups` | 名称、父分组、排序和时间，供 `hosts.group_id` 引用 |
| `tags` | 唯一名称、颜色和时间 |
| `host_tags` | 主机与标签多对多关联，联合主键，关联删除级联清理 |
| `recent_sessions` | 会话 ID、主机、起止时间、状态、错误和持续秒数，删除主机时级联清理 |
| `settings` | 键、文本值和更新时间，用于终端设置 |

主机默认端口为 22，连接超时为 10000ms，保活间隔为 30 秒，排序值为 0。
`private_key_path` 保存私钥路径，`private_key_ref` 是预留字段。
`password_ref` 和 `passphrase_ref` 关联加密凭据。名称、地址、用户名、分组以及
近期会话主机与起始时间等列建有索引。

分组、标签和近期会话的界面交付状态见 [项目现状](07-项目现状.md)。

## 加密凭据表

`credential_vault` 使用固定 `id = 1` 保存凭据库版本、salt、Argon2id 参数、
验证 nonce、验证密文和时间。当前参数为 64 MiB 内存、3 次迭代、并行度 1。

`encrypted_secrets` 以 `secret_ref` 为主键，保存随机 nonce、
XChaCha20-Poly1305 密文与时间。解锁后的主密钥保存在进程内存，释放时清零。
主密码不持久化，遗失后已加密凭据无法恢复。

## 凭据引用与更新

创建主机时的引用形式为：

```text
host:<host_id>:password
host:<host_id>:private_key_passphrase
```

更新凭据使用独立的新引用，具体值从主机记录读取。先写新密文，再提交主机配置，
成功后删除旧引用；失败时清理新引用并保留原凭据。引用清理由服务层协调，
表间未定义凭据引用外键。进程中断或清理失败可能留下孤立密文，当前尚无自动回收机制。

旧版 `wmcssh.json` 在凭据库初始化时迁移，完成后删除。服务器密钥信任记录使用
独立 `known_hosts` 文件，传输限制使用 `transfer-config.json`。
